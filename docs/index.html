    L'écran et les raccourcis
    
                
    
                    
    Ctrl+Entréeexécute le programme (comme ▶ Exécuter)
                        Ctrl+Espacepropose des mots ; une fonction choisie arrive avec ses arguments, le premier sélectionné
    
                    
    clic droit sur une fonctionva à sa définition, dans ce programme ou dans un autre programme du projet (pas pour une fonction prédéfinie) ; ↩ Retour ramène là où tu étais
                        sélectionner une fonctionmontre ses arguments en bas de l'éditeur
    
                    
    Ctrl+/met une ligne en commentaire, ou l'en sort
                        ⛶met l'éditeur, la console ou le canevas en plein écran (✕ ou Échap pour revenir)
    
                    
    >>>sous la console : exécute tout de suite une ligne, avec les variables du dernier programme (notes, longueur(notes)…)
                        Maj+Entrée · ↑ ↓dans la ligne >>> : passe à la ligne · rappelle les commandes déjà tapées
    
                    
    ▦ Donnéesmontre les onglets de données du projet (puis ✎ Code pour revenir)
                        λ LispEmontre le code LispE produit, avec ses numéros de ligne
    
                    
    ▤ Consoleen plein écran du canevas : fait venir la console dessous
                        ■ Arrêterarrête une animation (ou arrête() dans le programme)
    
                
    

                
                
    Le langage
    
                
    Un bloc est décalé de 4 espaces. La ligne qui l'ouvre se termine par :, et l'on
                    va toujours à la ligne après : rien ne s'écrit à droite du :.

                    Les instructions de LispE en français (…)
                    
    Ces noms sont d'autres noms des instructions de LispE (voir basic/français.lisp).
                        La dernière colonne donne le nom LispE, celui qui apparaît
                        dans « λ LispE ». Les angles sont en radians, sauf pour sinus et cosinus.

                        ligne(x1, y1, x2, y2)un segment
    
                    
    rectangle(x, y, l, h) · carré(x, y, c)contours (_plein : coloriés)
                        cercle(x, y, r) · disque(x, y, r)contour · rond colorié
    
                    
    ellipse(x, y, rx, ry) · triangle(…)(ellipse_pleine, triangle_plein)
                        polygone([[x, y], …])(polygone_plein)
    
                    
    texte(x, y, "Bonjour")écrit dans le canevas
                        taille_texte(30) · police("serif")style du texte
    
                    
    couleur_pixel(x, y)la couleur d'un point : [rouge, vert, bleu, opacité]
                        pixels(x, y, l, h) · pose_pixels(…)lit les points d'un rectangle · les redessine

                    beige, or, argent, bleu marine, et leurs nuances « clair » et « foncé » — ou une couleur CSS ("#ff8800").

                    Plusieurs élèves sur le même ordinateur
                    
    Par défaut, la Pythonerie est en mode Utilisateur unique : pas de connexion, l'utilisateur s'appelle « Unique ».
                        Pour un ordinateur partagé, décoche Utilisateur unique dans le menu ☰ : chaque élève tape son nom (bouton 👤)
                        avant d'exécuter du code, et ne voit que ses projets. Un deuxième clic sur 👤 le déconnecte : son projet rejoint sa liste,
                        et l'écran est vidé pour l'élève suivant. Avec "multi_utilisateur": true dans config.json, ce mode est imposé
                        à tout le monde. Avec serveur.py, une copie des projets exportés est gardée pour l'enseignant.
    
                
    
                
    
                    🔒 Protection des données
                    
    La Pythonerie est compatible avec le RGPD et ses équivalents canadiens (LPRPDE, Loi 25 du Québec) : tout s'exécute
                        dans le navigateur. Une fois la page chargée, rien ne transite par le réseau ; les programmes et le nom de l'élève restent
                        sur l'ordinateur. Il n'y a ni cookie, ni mesure d'audience, ni service tiers (l'éditeur et les polices sont fournis par le site).
