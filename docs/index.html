      Aide de la Pythonerie
      
                
            
      
            
      
                
      📖 Pour apprendre pas à pas, lis le mode d'emploi : il explique tout simplement et contient le glossaire de tous les mots.
      
                
      Pythonerie est un Python en français. Les blocs se reconnaissent à
                    l'indentation (4 espaces) et la ligne qui ouvre un bloc se termine par :.
                    Ctrl+Entrée exécute, Ctrl+Espace propose des mots, Ctrl+/ met une ligne en commentaire.
                    Sous la console, la ligne >>> exécute du code tout de suite, comme l'invite de Python :
                    tape notes pour voir le contenu de la variable, longueur(notes), x = 5…
                    Elle utilise les variables et les fonctions du dernier programme exécuté. Maj+Entrée passe à la ligne
                    (pour un pour ou un si), les flèches ↑ ↓ rappellent les commandes déjà tapées.
                    Les noms du langage s'écrivent avec leur orthographe : épaisseur,
                    carré, va_à, règle.
      
                
      Par défaut, la Pythonerie est en mode Utilisateur unique : pas de connexion, l'utilisateur s'appelle « Unique »
                    et le bouton 👤 est désactivé. Pour un ordinateur partagé, décoche Utilisateur unique dans le menu ☰ :
                    le bouton 👤 montre alors le nom de l'élève (« inconnu » au départ), qu'il faut taper pour exécuter du code.
                    Un deuxième clic déconnecte l'élève : la Pythonerie vérifie d'abord que ses programmes sont dans une archive,
                    puis efface tout son espace.
                    Dans le menu ☰, Créer une archive enregistre tous les programmes dans un fichier
                    nom_aaaa_mm_jj_hh_MM.json (dossier Téléchargements), que l'on peut donner à un autre élève.
                    Charger une archive remplace tous les programmes par ceux de l'archive ; s'il y en avait déjà, l'élève est déconnecté (en mode plusieurs élèves) ;
                    Annuler le chargement fait revenir les programmes d'avant.
      
                
      🔒 Protection des données : la Pythonerie est parfaitement compatible avec le RGPD et avec ses équivalents
                    canadiens (LPRPDE, Loi 25 du Québec). Tout s'exécute dans le navigateur : une fois la page chargée, rien ne transite
                    par le réseau. Les programmes et le nom de l'élève restent sur l'ordinateur, aucun serveur ne les reçoit, et il n'y a
                    ni cookie, ni mesure d'audience, ni service tiers (l'éditeur et les polices sont fournis par le site lui-même).

      Animation et interaction
      

      x = 0
couleur_balle = "rouge"

fonction bouge():
    x += 5              # += modifie la variable x du programme
    efface()
    couleur(couleur_balle)
    disque(x % 800, 300, 30)

animer(bouge, 30)       # toutes les 30 millisecondes

fonction clic(cx, cy):
    couleur_balle =: choisis(["rouge", "vert", "bleu"])   # =: modifie la variable du programme
quand_clic(clic)        # aussi : quand_souris(f), quand_glisse(f), quand_touche(f)
      
                
      Dans une fonction, x = … crée une variable locale (comme en Python) :
                    écris x =: … pour modifier la variable du programme. x += … modifie
                    directement la variable du programme si la fonction n'a pas de variable locale x.
      
                
      Le bouton « Arrêter » (ou arrête()) stoppe l'animation.
                    Attention : une boucle tantque Vrai: sans fin bloque la page — utilise plutôt animer.
                    Le bouton « λ LispE » montre le code LispE produit par le transpileur.
