        Aide de la Pythonerie
        
                
            
        
            
        
                
        📖 Pour apprendre pas à pas, lis le mode d'emploi : il explique tout simplement et contient le glossaire de tous les mots.
        
                
        Pythonerie est un Python en français. Les blocs se reconnaissent à
                    l'indentation (4 espaces) et la ligne qui ouvre un bloc se termine par :.
                    Ctrl+Entrée exécute, Ctrl+Espace propose des mots, Ctrl+/ met une ligne en commentaire.
                    Sous la console, la ligne >>> exécute du code tout de suite, comme l'invite de Python :
                    tape notes pour voir le contenu de la variable, longueur(notes), x = 5…
                    Elle utilise les variables et les fonctions du dernier programme exécuté. Maj+Entrée passe à la ligne
                    (pour un pour ou un si), les flèches ↑ ↓ rappellent les commandes déjà tapées.
                    Les noms du langage s'écrivent avec leur orthographe : épaisseur,
                    carré, va_à, règle.
        
                
        Par défaut, la Pythonerie est en mode Utilisateur unique : pas de connexion, l'utilisateur s'appelle « Unique »
                    et le bouton 👤 est désactivé. Pour un ordinateur partagé, décoche Utilisateur unique dans le menu ☰ :
                    le bouton 👤 montre alors le nom de l'élève (« inconnu » au départ), qu'il faut taper pour exécuter du code.
                    Avec "multi_utilisateur": true dans le fichier config.json du site, ce mode est imposé à tout le monde
                    et la case est désactivée ; chaque nouvel onglet commence alors avec un espace vide.
                    Un deuxième clic déconnecte l'élève : la Pythonerie vérifie d'abord que son projet a été exporté,
                    puis efface tout son espace.
        
                
        Le projet réunit les programmes et trois répertoires fixes, en haut de la liste : images, sons
                    et données. On y glisse des fichiers (ou on clique sur ＋) ; un programme les utilise par leur nom :
                    charge_image("chat.png"), charge_son("bravo.wav"), charge_données("notes.csv").
                    importe "outils" ajoute au programme le code du programme « outils » du projet ;
                    importe "jeux/décor" va le chercher dans un dossier.
                    Le nom du projet est affiché en haut de la liste (« Sans Nom » au départ) : un clic dessus le change.
                    Dans le menu ☰ : Nouveau projet commence un projet vide avec un nom ;
                    Renommer le projet change son nom ; Exporter le projet l'enregistre dans un fichier
                    nom_du_projet_aaaa_mm_jj_hh_MM.zip (dossier Téléchargements), avec le nom de l'élève en mode plusieurs élèves
                    (nom_du_projet_élève_aaaa_mm_jj_hh_MM.zip) ; un projet sans nom en reçoit un avant de partir.
                    Ce fichier zip contient les programmes, les onglets de données et les répertoires images, sons et données.
                    Avec serveur.py, une copie est aussi conservée sur le serveur, pour l'enseignant.
                    Charger un projet (un .zip, ou un .json) remplace le projet en cours (s'il y en avait un, l'élève est déconnecté en mode plusieurs élèves) ;
                    Annuler le chargement du projet fait revenir le projet d'avant.
                    Un projet du répertoire Matériels se charge d'un clic, et son nom peut ensuite être changé.
                    Coller un projet (JSON) charge un projet écrit d'un seul bloc de texte, comme ceux que prépare Claude.
        
                
        🔒 Protection des données : la Pythonerie est parfaitement compatible avec le RGPD et avec ses équivalents
                    canadiens (LPRPDE, Loi 25 du Québec). Tout s'exécute dans le navigateur : une fois la page chargée, rien ne transite
                    par le réseau. Les programmes et le nom de l'élève restent sur l'ordinateur, aucun serveur ne les reçoit, et il n'y a
                    ni cookie, ni mesure d'audience, ni service tiers (l'éditeur et les polices sont fournis par le site lui-même).

        Dessiner dans le canevas
        
                
        Le canevas mesure 800 × 600. Le point (0, 0) est en haut à gauche, y augmente vers le bas.
                    Survole le canevas pour voir les coordonnées. ⛶ Plein écran l'agrandit à tout l'écran, avec ■ Arrêter
                    et ✕ Quitter le plein écran (ou Échap). canevas(400, 400), au début du programme, change
                    sa taille (le dessin est effacé) ; largeur() et hauteur() donnent la taille actuelle.
                    À chaque exécution, il reprend sa taille de 800 × 600.

        Le bouton ▦ Données, au-dessus de l'éditeur, montre les onglets de données du projet ; il devient alors ✎ Code, pour revenir au programme.
                    On y tape ou colle des données, ou on y charge un fichier (📂). ＋ ajoute un onglet, − retire l'onglet ouvert (Don0 est seulement vidé), ↶ annule. À l'exécution, chaque onglet non vide devient
                    une variable : don0, don1… Les onglets appartiennent au projet : tous ses programmes
                    (et ceux qu'ils importent) voient les mêmes don0, don1…, et ils suivent le projet quand on l'exporte.
        
                
        Un nom seul ("chat.png") désigne un fichier du répertoire images ou sons du projet ; sinon, l'adresse est celle d'un fichier du site (exemples/médias/…) ou une adresse complète (https://…).
                    Une image d'un autre site s'affiche, mais le bouton « Image » ne peut plus enregistrer le dessin.
        

                
        Animation et interaction
        

        x = 0
couleur_balle = "rouge"

fonction bouge():
    x += 5              # += modifie la variable x du programme
    efface()
    couleur(couleur_balle)
    disque(x % 800, 300, 30)

animer(bouge, 30)       # toutes les 30 millisecondes

fonction clic(cx, cy):
    couleur_balle =: choisis(["rouge", "vert", "bleu"])   # =: modifie la variable du programme
quand_clic(clic)        # aussi : quand_souris(f), quand_glisse(f), quand_touche(f)
                        # quand_touche : "gauche", "droite", "haut", "bas", "espace", "entrée", "a"…
                        # dans la fonction d'animer : si touche_enfoncée("gauche"): … ; quand_relâche(f) : f(touche) au relâchement
                        # saisie("nom", 100, 100, f) : un champ de saisie ; Entrée appelle f(clef, valeur)
                        # active_saisie(clef), saisie_active(), largeur_saisie(l) ; nombre("2,5") donne 2.5
                        # aussi : bouton, case_à_cocher, bouton_radio, glissière, liste_déroulante,
                        # liste_hiérarchique, zone_édition ; valeur_objet(clef), change_objet(clef, valeur)
        
                
        Dans une fonction, x = … crée une variable locale (comme en Python) :
                    écris x =: … pour modifier la variable du programme. x += … modifie
                    directement la variable du programme si la fonction n'a pas de variable locale x.
        
                
        Le bouton « Arrêter » (ou arrête()) stoppe l'animation.
                    Attention : une boucle tantque Vrai: sans fin bloque la page — utilise plutôt animer.
                    Le bouton « λ LispE » montre le code LispE produit par le transpileur.
